# 知识点 ↔ 库 API ↔ 命令

第一章的七个知识点，各自**对应哪个库调用**、**哪条命令能验证**。
换成调库之后，这张表的用途正好变了：它是"这一章的每个知识点，在库里的入口在哪"的索引。

---

## 一览

| # | 知识点 | 库里的入口 | 命令 | 我们自己写的那部分 |
|---|---|---|---|---|
| 1 | 位姿与坐标系 | `spatialmath.SE3` / `SE3.RPY(order='zyx')` | `rkin pose` | 约定（见第 7 章） |
| 2 | 变换链 | `SE3 * SE3`、`T.inv()` | `rkin cam` | — |
| 3 | 正运动学 FK | `robot.fkine(q, end=…)` | `rkin fk` / `rkin panda-fk` | 二连杆闭式解（做对照） |
| 4 | 逆运动学 IK | `robot.ikine_LM(T, q0=…)` | `rkin ik` / `rkin panda-ik` | **二连杆闭式解**（库只给一组解） |
| 5 | 雅可比 | `robot.jacob0(q)` | `rkin jac` / `rkin panda-jac` | 闭式 `det(J)=L1L2sin(q2)`（做对照） |
| 6 | 奇异点 | `robot.manipulability(q, method=…)` + `numpy.linalg.svd` | `rkin sing` / `rkin panda-sing` | 体检报告的读数与判定 |
| 7 | 冗余与零空间 | `ikine_LM` 多初值 | `rkin panda-ik` | **解择优**（评分、就近、限位余量） |
| 8 | 真机约束 | `robot.qlim`、`end="panda_link8"` | `rkin panda-fk --frame tcp` | 限位校验、末端帧约定 |

> **两处仍然自己写**（库覆盖不到，见 `core/`）：二连杆的解析解（库给不出"肘上/肘下"两组解）、
> 可达性预筛（库的 `robot.reach` 实测返回 0，也没有"沿某方向能到多远"的 API）。

## 1 · 位姿与坐标系

**一句话**：说"在哪"必须先说"相对谁"；位姿 = 位置 + 姿态。

```bash
rkin pose --xyz 0.4 0.2 0.3 --rpy 0 0 90
```

看点：点 (0.1, 0, 0) 变换后是 **(0.4, 0.3, 0.3)**；报告里会并排打出四种表示（矩阵/RPY/轴角/四元数）
并互相重建验证。⚠️ 两个约定要盯住：`order='zyx'`（不是默认的 `'xyz'`）、四元数是 **(w,x,y,z)**。

---

## 2 · 变换链

```bash
rkin cam --all
```

| 算例 | 杯子在 base 下的位置 |
|---|---|
| 基准 | `[0.7830, 0.1634, 0.8]` |
| 杯子在相机里 x 变大 | `[0.9562, 0.2634, 0.8]` |
| 相机 yaw 改成 0° | `[0.8, -0.1, 0.8]` |

**杯子一动没动** —— 变的是"用什么语言描述它"。

---

## 3 · 正运动学

```bash
rkin fk --q1 0 --q2 90        # 二连杆：闭式解 + 与库对照（偏差 ~1e-16）
rkin panda-fk --case ppt_goal # Panda：库的 fkine
```

⚠️ Panda 的"末端"有两种定义，差 103.4mm：`end="panda_link8"`（法兰）
与默认（夹爪 TCP）。**同一台机器人、同一组关节角，两个数**——见第 8 节。

---

## 4 · 逆运动学

```bash
rkin ik --target 1 1                 # 二连杆：闭式解给两组
rkin ik --target 3 0                 # 无解（够不着，不是 bug）
rkin panda-ik --case ppt_goal        # Panda：库的 ikine_LM，多初值 + 冗余演示
```

**为什么二连杆不用库的 IK**：`ikine_LM` 只返回**一组**解，而"肘上/肘下两组解"是本节考点。
（另外给平面机械臂传 `mask` 会因库内部维数不匹配而抛错 —— 见第 7 章。）

---

## 5 · 雅可比

```bash
rkin jac --q1 0 --q2 90 --dx 0 0.1
```

- `J` 由 `robot.jacob0(q)` 给出；二连杆的 `det(J)` 另用闭式 `L1·L2·sin(q2)` 对照（两者一致）
- 解 `J·Δq = Δx` 得 `dq = [0.1, -0.1] rad = [5.73°, -5.73°]` —— 两个关节配合着动
- **它只在小步时成立**：0.5 m 的大位移误差立刻就出来

---

## 6 · 奇异点

```bash
rkin sing              # 四姿态扫描表（课件 07）
rkin sing --q2 0       # 只看奇异位姿：报告说明原因，dq 为空（不抛异常）
```

| q2 | 90° | 30° | 10° | 0° |
|---|---|---|---|---|
| cond(J) | 2.62 | 9.36 | 28.58 | inf |
| 1/σ_min | 1.62 | 4.33 | 12.83 | inf |

可操作度有现成的库实现（`robot.manipulability`，4 种定义），本项目算的那个与它逐位一致
（`core/singularity.py` 用的是 numpy SVD）。

## 7 · 冗余与零空间

```bash
rkin panda-ik --case ppt_goal          # 不同初值 → 不同关节角，末端位姿相同
rkin pick --observe 0.2 0 0 --prefer-config 0 -0.3 0 -2.2 0 2.0 0.8
```

实测（也是踩过的坑）：让解靠近理想姿态，实际只缩短 **0.00019 rad**，而"能动分量"看着有 0.0227 ——
差别在**夹角**：偏好方向与零空间接近正交时，能动分量再大也几乎不缩短距离。
所以在抓取流水线里，这一项是**评分的一部分**（权重 0.2），不是唯一目标。

---

## 8 · 真机约束：关节限位与"末端是哪个坐标系"

```bash
rkin panda-fk --case zero               # 法兰帧：0.9260
rkin panda-fk --case zero --frame tcp   # 夹爪帧：0.8226（与课件日志一致）
```

- 关节限位来自库的 `robot.qlim`（与本项目原来手写的 Franka 数据表逐位相同）
- 课件的"全零姿态"越过 q4 的限位（[-3.0718, -0.0698]），是数学参考位形，真机摆不出来
- **抓取流水线固定在夹爪帧**：库的 IK 只对模型默认末端求解，而且物理上抓东西的本来就是夹爪

## 把七个知识点串起来：抓取流水线

| # | 工序 | 知识点 | 由谁实现 |
|---|---|---|---|
| ① | 观测 → 本体位姿 | 位姿与坐标系、变换链 | spatialmath |
| ② | 可达性预筛 | 工作空间不是球 | **自研采样**（库没有这个 API） |
| ③ | 多初值 IK | IK 的多解 / 无解 / 迭代 | `ikine_LM`；二连杆用**闭式解** |
| ④ | 雅可比体检 | 雅可比与奇异点 | `robot.jacob0` + numpy SVD |
| ⑤ | 限位校验 | 真机约束（关节限位） | `robot.qlim` |
| ⑥ | 解择优 | 冗余与零空间 | **自研评分**（库不提供） |
| ⑦ | 微动可行性校验 | 雅可比干活：解一次小位移 | `robot.jacob0` + numpy |

```bash
rkin pick --observe 0.2 0 0 --plot                  # 一条命令跑完七道工序
rkin pick --observe 0.35 -0.05 0.15 --arm planar    # 二连杆走同一条流水线
```

### 失败也是一等公民

| 结论 | 会给出的信息 |
|---|---|
| `不在工作空间` | 沿该方向可达多少、目标多少、差多少，以及"换初值没用" |
| `姿态不可达` | 位置有余量但姿态做不到，最佳残差多少，建议换个抓取姿态 |
| `收敛精度不足` | 差一点就能收敛：最佳残差 vs 要求 |
| `所有解越关节限位` | 有几组解、越限位几组 |
| `所有解接近奇异` | σ_min 区间 |
| `微动不可行` | 末端动 1mm 需要多少度关节角、上限是多少 |

**验证过的例子** —— 同一位置，只换一个抓取姿态，结论完全不同：

```bash
rkin pick --observe 0.35 -0.05 0.15 --rpy 180 0 0   # 姿态不可达（位置够、方向做不到）
rkin pick --observe 0.35 -0.05 0.15 --rpy 0 90 0    # 可执行
```
