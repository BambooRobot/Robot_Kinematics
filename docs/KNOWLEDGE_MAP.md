# 知识点 ↔ 库 API ↔ 流水线工序

第一章的七个知识点，各自**对应哪个库调用**、在抓取流水线里**落在哪一道工序**。
入口是扁平 CLI：`rkin --observe X Y Z`（无子命令）；机型固定为 Franka Panda。

---

## 一览

| # | 知识点 | 库里的入口 | 在流水线里 | 我们自己写的那部分 |
|---|---|---|---|---|
| 1 | 位姿与坐标系 | `spatialmath.SE3` / `SE3.RPY(order='zyx')` | 工序 ①（观测 → 本体） | 约定（见 GUIDE 第 7 章） |
| 2 | 变换链 | `SE3 * SE3`、`T.inv()` | 工序 ①（`--mode camera`） | — |
| 3 | 正运动学 FK | `robot.fkine(q, end=…)` | 回验 / 绘图 | — |
| 4 | 逆运动学 IK | `robot.ikine_LM(T, q0=…)` | 工序 ③ 多初值 IK | — |
| 5 | 雅可比 | `robot.jacob0(q)` | 工序 ④ / ⑦ | — |
| 6 | 奇异点 | `robot.manipulability` + `numpy.linalg.svd` | 工序 ④ 体检 | 体检报告的读数与判定 |
| 7 | 冗余与零空间 | `ikine_LM` 多初值 | 工序 ⑥ 解择优 | **解择优**（评分、就近、限位余量） |
| 8 | 真机约束 | `robot.qlim`、夹爪 TCP 末端 | 工序 ⑤ 限位 | 限位校验、末端帧约定 |

> **仍然自己写**（库覆盖不到，见 `core/`）：可达性预筛（库的 `robot.reach` 实测返回 0，
> 也没有"沿某方向能到多远"的 API）。

## 1 · 位姿与坐标系

**一句话**：说"在哪"必须先说"相对谁"；位姿 = 位置 + 姿态。

流水线默认抓取姿态是 `--rpy 180 0 0`（工具 z 朝下）。⚠️ 两个约定要盯住：
`order='zyx'`（不是默认的 `'xyz'`）、四元数是 **(w,x,y,z)**。

课件基准变换算例：点 (0.1, 0, 0) 在六元组 (0.4,0.2,0.3,0,0,90°) 下变成 **(0.4, 0.3, 0.3)**。

---

## 2 · 变换链

默认 `--mode camera`：观测先经相机外参变到本体坐标。

| 算例（课件） | 杯子在 base 下的位置 |
|---|---|
| 基准 | `[0.7830, 0.1634, 0.8]` |
| 杯子在相机里 x 变大 | `[0.9562, 0.2634, 0.8]` |
| 相机 yaw 改成 0° | `[0.8, -0.1, 0.8]` |

**杯子一动没动** —— 变的是"用什么语言描述它"。若观测已是本体坐标，用 `--mode base`。

---

## 3 · 正运动学

流水线内部用 `robot.fkine` 做残差回验与出图。⚠️ Panda 的"末端"有两种定义，差 103.4mm：
`end="panda_link8"`（法兰）与默认（夹爪 TCP）。**同一台机器人、同一组关节角，两个数**——见第 8 节。

---

## 4 · 逆运动学

工序 ③：对多个初值调用 `ikine_LM`。可能多解、无解、或残差不够小。
用 `--seeds` 覆盖初值个数；收敛判据由配置 / `--tol` 控制。

---

## 5 · 雅可比

工序 ④ / ⑦：`J = robot.jacob0(q)`（形状 **6×7**）。
SVD 给出 σ_min、条件数、最难运动方向；微动校验再解一次小位移 `J·Δq = Δx`。

---

## 6 · 奇异点

流水线把"接近奇异"当成候选解的淘汰条件（`pick.min_sigma`）。
可操作度有现成的库实现（`robot.manipulability`），本项目算的那个与它逐位一致
（`core/singularity.py` 用的是 numpy SVD）。全零姿态是奇异位形（σ_min ≈ 1e-16）。

---

## 7 · 冗余与零空间

```bash
rkin --observe 0.2 0 0 --prefer-config 0 -0.3 0 -2.2 0 2.0 0.8
```

不同初值 → 不同关节角，末端位姿相同。实测（也是踩过的坑）：让解靠近理想姿态，
实际只缩短 **0.00019 rad**，而"能动分量"看着有 0.0227 —— 差别在**夹角**：偏好方向与零空间
接近正交时，能动分量再大也几乎不缩短距离。所以在抓取流水线里，这一项是**评分的一部分**
（权重 0.2），不是唯一目标。

---

## 8 · 真机约束：关节限位与"末端是哪个坐标系"

- 关节限位来自库的 `robot.qlim`
- 课件的"全零姿态"越过 q4 的限位（[-3.0718, -0.0698]），是数学参考位形，真机摆不出来
- 零位姿：法兰 **0.9260** / 夹爪 TCP **0.8226**（差 103.4 mm）
- **抓取流水线固定在夹爪帧**：库的 IK 只对模型默认末端求解，而且物理上抓东西的本来就是夹爪

---

## 把七个知识点串起来：抓取流水线

| # | 工序 | 知识点 | 由谁实现 |
|---|---|---|---|
| ① | 观测 → 本体位姿 | 位姿与坐标系、变换链 | spatialmath |
| ② | 可达性预筛 | 工作空间不是球 | **自研采样**（库没有这个 API） |
| ③ | 多初值 IK | IK 的多解 / 无解 / 迭代 | `ikine_LM` |
| ④ | 雅可比体检 | 雅可比与奇异点 | `robot.jacob0` + numpy SVD |
| ⑤ | 限位校验 | 真机约束（关节限位） | `robot.qlim` |
| ⑥ | 解择优 | 冗余与零空间 | **自研评分**（库不提供） |
| ⑦ | 微动可行性校验 | 雅可比干活：解一次小位移 | `robot.jacob0` + numpy |

```bash
rkin --observe 0.2 0 0 --plot                  # 一条命令跑完七道工序
```

### 失败也是一等公民

| 结论 | 会给出的信息 |
|---|---|
| `不在工作空间` | 沿该方向可达多少、目标多少、差多少，以及"换初值没用" |
| `姿态不可达` | 位置有余量但姿态做不到，最佳残差多少，建议换个抓取姿态 |
| `收敛精度不足` | 差一点就能收敛：最佳残差 vs 要求 |
| `所有解越关节限位` | 有几组解、越限位几组 |
| `所有解接近奇异` | σ_min 区间 |
| `微动不可行` | 末端动 1mm 需要多少度关节角、上限是多少 |

**验证过的例子** —— 同一位置，只换一个抓取姿态，结论完全不同：

```bash
rkin --observe 0.35 -0.05 0.15 --rpy 180 0 0   # 姿态不可达（位置够、方向做不到）
rkin --observe 0.35 -0.05 0.15 --rpy 0 90 0    # 可执行
```
